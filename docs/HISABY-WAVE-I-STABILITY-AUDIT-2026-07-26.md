## ما شُحن

### 1) إصلاح دوران لا نهائي
- تسوية بنكية، تفاصيل الجرد، طلب مطعم، زيارات الإدارة، سجل التدقيق، إعدادات الشركة

### 2) تمرير روابط الإعدادات
- بعد التحميل: `#two-factor` · `#logo` · `#vat` · `#company` عبر `scrollIntoView`

### 3) قفل الحساب عند الدخول
- رسالة أوضح مع وقت الفتح إن وُجد في الاستجابة
- إزالة نص «شغّل seed» من واجهة العميل

### 4) تدقيق Auth
- أحداث: `LOGIN_OK` · `LOGIN_FAIL` · `ACCOUNT_LOCK` في سجل التدقيق
- فلاتر جديدة في تقرير التدقيق

### 5) حد معدّل لمسارات حسّاسة
- إنشاء مفتاح API · OTP واتساب حماية مزدوجة · إنشاء مستخدم: 10/دقيقة

### 6) منارة أخطاء المتصفح
- `POST /api/public/client-errors` (throttle 30/دقيقة)
- `ClientErrorBeacon` يرسل أخطاء النافذة/الوعود غير المعالجة

---

## تحقق سريع

1. افتح `/settings#two-factor` — يجب التمرير لقسم 2FA بعد التحميل.  
2. أوقف API وافتح تسوية بنكية / جرد — زر إعادة محاولة لا دوران أبدي.  
3. سجّل دخول فاشل 5 مرات — قفل + حدث `ACCOUNT_LOCK` في التدقيق.  
4. أنشئ مفتاح API بسرعة متكررة — يُرفض بعد الحد.
