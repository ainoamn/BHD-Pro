# ترقية نظام المطاعم العالمي — Hisaby Resto (يوليو 2026)

وثيقة شاملة لما شُحن في موجات المطاعم حتى Wave 21، ومعايير التشغيل، وما تبقّى.

---

## الرؤية

نظام مطاعم بمعايير عالمية: أرضية طاولات، مطبخ حي، ضيف QR، حجز ذاتي، ولاء، توصيل، ورديات، وتسعير حسب فترة اليوم — متكامل مع المحاسبة والكاشير (Hisaby).

---

## ما اكتمل (حسب الموجة / الموضوع)

### أرضية التشغيل
- مناطق وطاولات + حالات (حرة / محجوزة / مشغولة / فاتورة)
- طلبات dine-in / takeaway / delivery
- كورسات وإطلاق للمطبخ (fire)
- نقل / دمج / تقسيم الطلب
- Void / Comp بضوابط مزدوجة
- بقشيش + رسوم خدمة + إسناد البقشيش
- طلب حسب المقعد + تسوية بالمقعد / بالتساوي
- قائمة انتظار + إجلاس
- حجوزات الموظفين

### المطبخ و KDS
- طابور محطات + بث SSE
- Rush / Hold / Recall
- Expo pass
- SLA قابل للضبط في `restoConfig`
- حفظ فلتر المحطة في المتصفح
- عرض رقم المقعد على التذكرة

### الضيف
- طلب عبر QR `/order/[token]` (قائمة، كورس، إضافات، ولاء، دفع)
- **اختيار المقعد** Shared أو 1..N
- استدعاء نادل / فاتورة / ماء
- طباعة بطاقات QR

### الحجز الإلكتروني
- إعدادات في `/resto/settings` (تفعيل، slug، سعة، ساعات، تأكيد/إشعار تلقائي)
- صفحة عامة `/reserve/[slug]` — تواريخ وفترات متاحة حسب الطاولات
- إدارة الحجز `/book/[token]` — تأكيد / إلغاء
- إشعار واتساب → SMS (قائمة انتظار + حجز)

### القائمة والمخزون
- 86 يدوي + مزامنة مخزون
- مسببات حساسية ووسوم غذائية
- توفر حسب فترة اليوم (`dayParts`)
- **أسعار حسب الفترة** (`dayPartPrices`) — Wave 21
- وصفات BOM تخصم عند الإغلاق المدفوع
- محطات منتج

### التكامل
- جسر ورديات / درج نقدي داخل قشرة المطعم
- ولاء (ربط جوال، اكتساب)
- استيراد توصيل خارجي (API ingest)
- تقارير تشغيلية

## Migrations المطلوبة على الإنتاج

بعد كل نشر Render:

```bash
npx prisma migrate deploy
```

أهم الهجرات ذات الصلة بالمطاعم مؤخراً:
- `20260726170000_resto_guest_notify`
- `20260726180000_resto_public_booking` (`source` على الحجوزات)
- `20260726170000_product_sold_by_weight` (POS)
- `20260726190000_product_day_part_prices` (**Wave 21**)

---

## إعداد سريع للمشغّل

1. ربط مستودع المطعم في الإعدادات.
2. ضبط جدول الفترات (فطور/غداء/عشاء/ليلي) في إعدادات المطعم.
3. على `/resto/menu`: تفعيل الفترات + أسعار اختيارية لكل فترة.
4. تفعيل الحجز العام ونسخ رابط `/reserve/{slug}`.
5. ضبط واتساب/SMS لإشعارات الضيوف.
6. طباعة QR للطاولات من صفحة الطباعة.
