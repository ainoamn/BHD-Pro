# حسابي للمطاعم — دليل سريع

**المسار:** `/resto` — زر واحد «المطاعم» بجانب المحاسبة والكاشير.

## فصل المخازن (مهم)

1. من المحاسبة أنشئ مخزناً بقطاع **RESTAURANT** (مطاعم) ومخزناً منفصلاً للكاشير إن لزم (**RETAIL**).
2. عيّن أصناف الوجبات لهذا المخزن (مستودع المنتج الافتراضي أو رصيد WarehouseStock).
3. من إعدادات المطاعم: اختر **مخزن المطاعم** عند الربط — القائمة تعرض فقط أصناف ذلك المخزن.
4. الكاشير بالمثل: اربطه بمخزن التجزئة حتى لا تختلط أصناف المطعم مع البقالة.

## التدفق اليومي

1. تفعيل الربط + اختيار المخزن
2. تهيئة صالة أو سفري (`/resto/takeaway`)
3. أضف أصنافاً من قائمة المخزن المربوط → إرسال مطبخ (KDS مع تنبيه صوتي)
4. وصفات `/resto/recipes` للطبق غير المتتبَّع → خصم مكونات عند الإغلاق المدفوع
5. إغلاق ودفع → فاتورة عبر POS من مخزن المطاعم
6. حجوزات `/resto/reservations` — إجلاس يفتح طلباً على الطاولة
7. تقارير `/resto/reports`
