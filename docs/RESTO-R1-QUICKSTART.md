# حسابي للمطاعم — دليل سريع

**المسار:** `/resto` — زر واحد «المطاعم» بجانب المحاسبة والكاشير، وأقسام داخلية.

## التدفق اليومي الأساسي

1. تفعيل الربط (الإعدادات)
2. تهيئة صالة أو اضغط **سفري**
3. أضف أصنافاً (اختَر محطة مطبخ/بار إن وُجدت) → إرسال مطبخ
4. شاشة المطبخ `/resto/kitchen` — صفِّ حسب المحطة
5. **إغلاق ودفع نقداً / بطاقة** → فاتورة في الكاشير + خصم مخزون + قيد
6. تقارير `/resto/reports`

## الإغلاق والإلغاء

| الخيار | الأثر |
|--------|--------|
| نقداً / بطاقة | `PosService.createSale` + `invoiceId` على الطلب |
| إغلاق تشغيلي فقط | يحرر الطاولة بلا فاتورة |
| إلغاء الطلب | مدير / RESTO_MANAGER — يحرر الطاولة |

## محطات المطبخ

من **الإعدادات** أضف محطات (مطبخ، بار، …). عند إضافة صنف من صفحة الطلب اختر المحطة؛ شاشة KDS تُصفَّى لكل محطة. البذرة الأولى تضيف مطبخ + بار.
