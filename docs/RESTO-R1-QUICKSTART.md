# حسابي للمطاعم — دليل سريع

**المسار:** `/resto` — منتج واحد بشريط أقسام داخلي (صالة · قائمة · مطبخ · تقارير · إعدادات)

بجانب المحاسبة والكاشير يظهر زر واحد فقط: **المطاعم**.

## التدفق

1. تفعيل الربط من الإعدادات  
2. تهيئة صالة تجريبية إن لزم  
3. فتح طاولة → أصناف → إرسال مطبخ  
4. متابعة `/resto/kitchen`  
5. تقارير `/resto/reports` أو من مركز التقارير في المحاسبة  

## التقارير

`GET /resto/reports/summary?days=7` — طلبات، إيراد تشغيلي، متوسط تحضير، ذروة ساعة، طاولات، أصناف أعلى.
