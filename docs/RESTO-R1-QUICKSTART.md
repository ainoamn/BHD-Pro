# حسابي للمطاعم — دليل سريع

**المسار:** `/resto` — زر واحد «المطاعم» بجانب المحاسبة والكاشير، وأقسام داخلية.

## التدفق العالمي الأساسي

1. تفعيل الربط  
2. تهيئة صالة أو اضغط **سفري**  
3. أضف أصنافاً → إرسال مطبخ (اختياري للسفري السريع)  
4. **إغلاق ودفع نقداً / بطاقة** → فاتورة في الكاشير + خصم مخزون + قيد  
5. تقارير `/resto/reports`

## الإغلاق

| الخيار | الأثر |
|--------|--------|
| نقداً / بطاقة | `PosService.createSale` + `invoiceId` على الطلب |
| إغلاق تشغيلي فقط | يحرر الطاولة بلا فاتورة |

Migration: `resto_order_invoice` — نفّذ `npx prisma migrate deploy` بعد النشر.
