# موجة EP — صدق أخطاء الموافقة المزدوجة وإرسال المستندات

**التاريخ:** 28 يوليو 2026

## الهدف

إنشاء طلب موافقة مزدوجة وإرسال OTP واتساب، ومسار مشاركة/إرسال فاتورة، كانت تعرض نصوصاً عامة وتخفي سبب الـ API. فشل تحميل الفاتورة بعد التحصيل أو فتح المشاركة كذلك.

## التغييرات

| ملف | ماذا |
|-----|------|
| `dual-approval-modal.tsx` | `apiErrorMessage` لطلب الموافقة وOTP |
| `send-document-modal.tsx` | صدق أخطاء رابط المشاركة / بريد الخادم (+ عرض `emailError` إن وُجد) |
| `accounting-module.tsx` | صدق بعد التحصيل، تحميل PDF، فتح مشاركة |

## سلوك

- فشل طلب موافقة أو OTP → toast برسالة Nest
- فشل إرسال فاتورة من الخادم → الرسالة الفعلية بدل `sendError` فقط
