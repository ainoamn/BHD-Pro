# موجة EI — صدق أخطاء تعليق سلة الكاشير

**التاريخ:** 28 يوليو 2026

## الهدف

`parkCart` كان يبتلع خطأ الـ API ويعرض فقط «تعذّر التعليق» — يخفي أسباباً مثل لا وردية مفتوحة (عند عربون نقدي)، أسطر فارغة، أو نقص `heldMethod`.

## التغييرات

| ملف | ماذا |
|-----|------|
| `pos/page.tsx` | `apiErrorMessage` في `catch` لتعليق السلة |
| `utils.ts` | خرائط عربية لأخطاء المسودة/العربون/الوردية |

## سلوك

- فشل التعليق → toast برسالة الـ API (مترجمة عند التعرّف) بدل نص عام فقط

## التالي

Cloudflare / Sentry / OTP يدوياً · هيّئ `whatsappNotifyPhones` عند الحاجة.
