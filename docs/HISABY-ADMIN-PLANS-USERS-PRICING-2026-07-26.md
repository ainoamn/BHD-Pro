## 2) لوحة تحكم المنصة (`/admin`)

### 2.1 الدخول والحماية

- يتطلب مشغّل منصة (بريد bootstrap أو سجل `PlatformOperator`).
- المالك الأساسي (`admin@hisaby.pro` وغيرها من bootstrap) **محمي**: لا تعطيل/حذف/تقييد صلاحياته من الواجهة.
- نائب المالك (`isDeputy`): يعيّنه المالك فقط.

### 2.2 الأقسام

| القسم | المسار | الوظيفة |
|-------|--------|---------|
| المؤشرات | `/admin` | شركات، مستخدمون، زيارات، إيرادات (مع كاش ~45–60ث) |
| الشركات | `/admin/tenants` | باقة، انتهاء، حدود، تخفيض دائم، دولة/هاتف |
| المستخدمون | `/admin/users` | بحث/فلترة، تفاصيل، تفعيل، حذف، إعادة كلمة مرور، ترقية باقة الشركة |
| مشرفو المنصة | `/admin/operators` | تعيين صلاحيات المنصة + نائب |
| الاشتراكات والمدفوعات | `/admin/billing` | فواتير اشتراك |
| الباقات والعروض | `/admin/plans` | أسعار، تخفيض سنوي، شجرة صلاحيات لكل باقة، عروض ترويجية |
| الزيارات | `/admin/visits` | مسارات، دول، أيام |
| بوابات الدفع | `/admin/gateways` | Thawani / Stripe / PayPal / MOCK_CARD |
| الإعدادات | `/admin/settings` | وضع الصيانة |

## 3) الباقات والصلاحيات المتداخلة

### 3.1 نموذج التخزين

على `PlanDefinition.features` (JSON):

```json
{
  "accounting": true,
  "pos": false,
  "modules": {
    "sales": {
      "enabled": true,
      "transactionLimit": 100,
      "grants": { "invoices": true, "quotations": true }
    }
  }
}
```

- الكتالوج: `frontend/src/lib/plan-access-catalog.ts` و`backend/src/common/plan-access-catalog.ts`
- المجموعات: محاسبة · كاشير · مطاعم
- الواجهة: `PermissionTree` (وضع `compact` لأعمدة المقارنة)

### 3.2 واجهة المقارنة

في `/admin/plans` كل باقة = عمود:

1. أسماء عربي/إنجليزي  
2. شهري · **تخفيض سنوي %** · إجمالي سنوي  
3. حدود فواتير/مستخدمين  
4. شجرة الصلاحيات كاملة  
5. زر حفظ مستقل لكل باقة  

مرّر أفقيًا لمقارنة الباقات دون الصعود/النزول بين بطاقة واحدة ومحرّر سفلي.

## 4) تسعير الاشتراك (شهري / سنوي / تخفيض)

### 4.1 الحقل الجديد

`PlanDefinition.yearlyDiscountPct` (Decimal، افتراضي 20) — يُطبَّق عبر `prisma db push` عند نشر Render.

### 4.2 المعادلات

| الإجراء | النتيجة |
|---------|---------|
| تغيير الشهري أو التخفيض % | `سنوي = شهري × 12 × (1 − تخفيض%/100)` |
| تغيير السنوي | يبقى الشهري كسعر قائمة؛ يُشتق التخفيض % |
| زر «الشهري = السنوي ÷ 12» | يعيد ضبط السعر الشهري من الإجمالي السنوي |

المساعدات المشتركة:

- `frontend/src/lib/plan-pricing.ts`
- `backend/src/common/plan-pricing.ts`

### 4.3 API عام للصفحة الرئيسية

```
GET /api/public/plans
```

يعيد الباقات النشطة: `monthlyPrice`, `yearlyPrice`, `yearlyDiscountPct`, الأسماء، الحدود.

### 4.4 الصفحة الرئيسية

- زر **استعراض الشهري والسنوي** في الـ hero → ينتقل إلى `#pricing`
- تبديل شهري/سنوي يعرض السعر الحي + شارة التوفير + السعر الشهري المكافئ
- **جلب الخادم (SSR):** `app/page.tsx` يقرأ `GET /api/public/plans` عند البناء/الطلب (`revalidate: 15`) ويمرّر الأسعار لـ `LandingPage` حتى تظهر فورًا في HTML
- **تحديث المتصفح:** `fetch('/backend-api/public/plans')` بدون كوكيز مصادقة + عند التركيز وكل 60 ثانية
- **API عام:** `publicPlans()` يُبطّل كاش الكتالوج ثم يقرأ من قاعدة البيانات حتى تنعكس تعديلات `/admin/plans` فورًا

**تحقق سريع:** بعد حفظ باقة في `/admin/plans`، افتح `/` أو حدّثها — يجب أن تظهر `monthlyPrice` / `yearlyPrice` / شارة التخفيض نفسها من `GET /api/public/plans`.

### 4.5 داخل التطبيق

- `/subscription`: تبديل شهري/سنوي + شارة `−N%` عند السنوي
- الدفع يستخدم `yearlyPrice` / `monthlyPrice` من الكتالوج ثم عروض ترويجية ثم تخفيض الشركة الدائم (أفضل نسبة)

## 5) مستخدمو المنصة (`/admin/users`)

- تصميم فاتح متناسق مع باقي `/admin` (أبيض / تيل)
- **قائمة يسار + لوحة تفاصيل لاصقة يمين** (بدل مودال طويل)
- تبويبات اللوحة: الباقة · المدفوعات · الجلسات
- البحث يُطبَّق عند الإرسال فقط (لا إعادة جلب مع كل حرف)
- القائمة خفيفة (بدون جلسات لكل صف)

---

## 6) مستخدمو الشركة (`/users`)

### 6.1 عند الإضافة

1. اختر الدور → تُملأ صلاحيات افتراضية (`ROLE_DEFAULT_PERMISSIONS`)
2. شجرة مجموعات: محاسبة وإدارة · كاشير · مطاعم
3. لكل وحدة: **مخفي / عرض / تعديل**
4. تُحفظ مع إنشاء المستخدم (`permissions` JSON)

### 6.2 بعد الإنشاء

زر **صلاحيات** + «إعادة لافتراضي الدور».  
مدير الشركة (`ADMIN`) دائمًا صلاحية كاملة (لا تُقيَّد).

الملفات:

- `frontend/src/components/users/user-access-tree.tsx`
- `frontend/src/lib/module-permissions.ts`
- `backend/src/common/module-permissions.ts`

## 7) تخفيض الشركة الدائم وترقية يدوية

حقول على `Company`:

- `permanentDiscountPct`
- `permanentDiscountNote`

تُعدَّل من `/admin/users` (لوحة الباقة) أو `/admin/tenants`، وتُطبَّق في تسعير checkout الاشتراك.

## 10) تحقق سريع بعد النشر

1. `/admin/plans` — غيّر الشهري → يتحدّث السنوي؛ احفظ باقة.  
2. الصفحة الرئيسية — زر الاستعراض + تبديل سنوي يظهر تخفيضًا.  
3. `/users` — أضف مستخدمًا بدور كاشير وتحقق من الشجرة الافتراضية.  
4. `/admin/users` — افتح مستخدمًا من القائمة (لوحة جانبية لا مودال).  
5. `GET /api/public/plans` — يعيد JSON بأسعار حية.
