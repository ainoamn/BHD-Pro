# موجة DD — صدق إشعار إيصال العميل بعد بيع الكاشير

**التاريخ:** 28 يوليو 2026

## الهدف

بعد البيع كان الإشعار (`notifyPosSale`) يُطلق في الخلفية دون نتيجة للواجهة — الكاشير يرى «تم البيع» فقط حتى في وضع mock أو عند فشل القنوات.

## التغييرات

| ملف | ماذا |
|-----|------|
| `pos.service.ts` | `awaitCustomerNotify` للبيع · بوابة هاتف أو بريد · إرجاع `customerNotify` مع الفاتورة |
| `pos/page.tsx` | toast ثانٍ: ok / mock / partial / fail |
| `pos-copy.ts` | نصوص `saleNotify*` |

## سلوك

- walk-in بلا قناة: لا حقل / لا toast إضافي
- mock فقط → 🧪 · فشل فقط → تحذير · مزيج → جزئي · حي → نجاح الإيصال
- void/refund يبقيان fire-and-forget (لا يُبطئان العملية الحساسة)

## التالي
