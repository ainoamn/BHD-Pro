# موجة BY — إبطال كاش لوحة التحكم عند الكتابة

**التاريخ:** 28 يوليو 2026

## الهدف

موجة BV خزّنت إحصاءات Dashboard في Redis بـ TTL قصير دون إبطال عند البيع/الدفع. مع `REDIS_URL` قد تبقى مؤشرات الشهر/التحصيل خاطئة حتى انتهاء TTL. هذه الموجة تبطل الكاش فوراً عند الطفرات المالية.

## التغييرات

| ملف | ماذا |
|-----|------|
| `redis.service.ts` | `invalidateDashboardStats(companyId)` — حذف مفتاح واحد |
| `invoices.service.ts` | إبطال بعد إنشاء/تعديل/حالة/دفع/عكس/إرسال/حذف |
| `pos.service.ts` | إبطال مع كاش الكتالوج + بعد البيع والإلغاء |
| `dashboard/page.tsx` | تلميح خفيف عند `cached: true` |

## سلوك

- بدون Redis: لا تغيير
- مع Redis: البيع/الدفع يفرّغ الكاش؛ القراءة التالية تعيد الحساب من Neon

## التالي

Cloudflare/Sentry يدوياً · أرشفة docs.
