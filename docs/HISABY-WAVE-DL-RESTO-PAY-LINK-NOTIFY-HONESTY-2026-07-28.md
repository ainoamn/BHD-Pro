# موجة DL — صدق إشعار رابط دفع طاولة المطعم

**التاريخ:** 28 يوليو 2026

## الهدف

إنشاء رابط دفع أونلاين من خريطة الطاولات كان ينسخ/يفتح الرابط فقط دون إرسال للضيف ودون toast صدق.

## التغييرات

| ملف | ماذا |
|-----|------|
| `resto-guest-notify.service.ts` | نوع `PAY_LINK` + نص الرسالة |
| `resto.service.ts` | إشعار الضيف عند إنشاء رابط جديد · إرجاع `notify` |
| `resto/page.tsx` · `resto-copy.ts` | toast إنشاء الرابط + صدق واتساب/SMS |
