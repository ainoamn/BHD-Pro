# موجة CP — صدق إشعار الحجز العام (ضيف)

**التاريخ:** 28 يوليو 2026

## الهدف

صفحة `/reserve/[slug]` كانت دائماً تقول «تحقق من واتساب/الرسائل» بعد الحجز، حتى عندما `autoNotify` معطّل أو القناة mock أو فشل الإرسال. الـ API يعيد `notify` منذ CI؛ الواجهة تجاهلته.

## التغييرات

| ملف | ماذا |
|-----|------|
| `reserve/[slug]/page.tsx` | حفظ `notify` · نص نجاح حسب live / mock / لا إشعار |
| `resto.service.ts` | نوع `notify` يتضمن `mock`/`mode` |

## التالي

Wave CQ (إيقاظ API عند الدخول) · Cloudflare / Sentry يدوياً.
