# موجة EB — صدق إشعار مستلم البقشيش عند الإغلاق

**التاريخ:** 28 يوليو 2026

## الهدف

عند إغلاق طلب مدفوع ببقشيش منسوب لنادل، كان الاعتماد على التقارير فقط بلا إشعار فوري للمستلم — فجوة صدق مقابل إيصال العميل الذي يظهر في الواجهة.

## التغييرات

| ملف | ماذا |
|-----|------|
| `resto.service.ts` | `notifyTipAssignee` (واتساب ثم بريد) · `tipNotify` في رد `closeOrder` |
| `pos-notify-toast.ts` | `toastTipNotify` |
| `resto/page.tsx` · `orders/[id]` · `api.ts` · `resto-copy` | toast عند الإغلاق المدفوع |

## سلوك

- بقشيش > 0 + مستلم → واتساب إن وُجد هاتف، وإلا بريد
- mock / فشل / بلا هاتف أو بريد → toast صريح
- الإغلاق التشغيلي (soft) بلا إشعار

## التالي

Cloudflare / Sentry / OTP يدوياً · تأكد أرقام/بريد المستخدمين في الملف الشخصي.
