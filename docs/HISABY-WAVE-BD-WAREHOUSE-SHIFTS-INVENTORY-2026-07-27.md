# موجة BD — إكمال مستودع الموظف (ورديات + مخزون)

**التاريخ:** 27 يوليو 2026  
**بعد:** Wave BC

## ما أُكمل

| البند | التفاصيل |
|-------|----------|
| ورديات | قائمة المستودع للمدير فقط؛ الكاشير يرى مستودعه |
| فتح/إغلاق وردية | الـ API يفرض مستودع المنزل على غير المديرين |
| حركة نقد | نفس القفل على مستودع الوردية |
| مخزون الكاشير | يعرض أصناف مستودع الموظف؛ المدير يختار المستودع |

## تذكير إنتاج

```bash
npx prisma migrate deploy
```

ثم عيّن «مستودع الموظف» من صفحة المستخدمين.
