# Hisaby — موجة AO: حماية حذف مشروع/حساب/ضريبة + صدق واجهة (26 يوليو 2026)

**الفرع:** `main` · بعد موجة AN  
**المستودع:** [ainoamn/BHD-Pro](https://github.com/ainoamn/BHD-Pro)

---

## ما شُحن

### 1) حماية حذف ERP إضافية
- مشروع مرتبط بقيود/فواتير → تعطيل (`ON_HOLD`) بدل الحذف الصلب
- حساب بدفتر أو رصيد → تعطيل بدل رفض/حذف
- معدل ضريبة غير افتراضي → تعطيل (`isActive: false`) بدل حذف صلب

### 2) صدق واجهة
- مساعد `apiErrorMessage` في `frontend/src/lib/utils.ts`
- صفحات: التزامات · موظفون · دليل حسابات · مشاريع · مراكز تكلفة · مخزون · جرد · مذكرات تسليم · تسوية بنكية · تنبيهات إدارة · مستخدمون — تعرض رسالة API عند الخطأ

---

## تحقق سريع

1. حذف مشروع بفواتير → deactivated.  
2. حذف حساب له قيود → deactivated.  
3. حذف معدل ضريبة غير افتراضي → isActive false.  
4. فشل حفظ مستخدم/التزام → toast برسالة الخادم.
