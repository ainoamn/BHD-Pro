# ترقية Hisaby — Wave 18 POS (يوليو 2026)

**الهدف:** عربون على السلات المعلّقة، تدقيق الموافقات بسبب إلزامي، وشحن رصيد المتجر من أرضية البيع.

## ما شُحن

1. **عربون / مبلغ محجوز عند التعليق (held tender)**
   - حقول `heldAmount` / `heldMethod` / `heldMovementId` على `pos_drafts`
   - نقداً → حركة صندوق IN مرتبطة بالوردية
   - عند الاسترجاع: يبقى العربون ويُحسب المتبقي؛ عند إتمام البيع يُستهلك العربون
   - حذف سلة بعربون نقدي → OUT لإرجاع المبلغ (قد يتطلب موافقة حسب حد الإخراج)
   - Migration: `20260726150000_pos_draft_held_tender`

2. **سبب إلزامي للموافقة المزدوجة**
   - حقل `reason` في `DualApprovalDto` (3–200 حرف)
   - واجهة في `DualApprovalModal` + تسجيل في التدقيق

3. **شحن رصيد المتجر من الكاشير**
   - `POST /pos/store-credit/top-up`
   - نقداً يُرحَّل أيضاً كحركة صندوق IN
   - زر «شحن رصيد» بجانب اختيار العميل

4. **ملاحظة فتح الوردية (UI)**
   - حقل ملاحظات عند فتح الوردية (الـ API كان جاهزاً)
