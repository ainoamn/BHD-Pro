# ترقية Hisaby — Wave 11 POS (يوليو 2026)

**الهدف:** ثقة المسح بالصوت، تشغيل SMS/البريد للإيصالات، ولوحة مدير أغنى وأسرع.

## ما شُحن

1. **صوتيات المسح** — نجاح · تحذير مخزون منخفض · رفض (تجاوز المخزون / باركود غير معروف)
2. **قنوات إيصال قابلة للضبط** — تبديل مستقل لـ WhatsApp / Email / SMS · زر «إرسال SMS» على آخر بيع · `POST /pos/sales/:id/notify`
3. **لوحة ورديات اليوم v2** — عمود إلغاءات · نبضة للورديات المفتوحة · تحديث كل 15ث · بطاقة لوحة التحكم تفتح `/pos/shifts`

## إعداد

Security / Dual control:
- تفعيل/إيقاف إيميل وSMS للإيصالات
- Twilio: `TWILIO_*` أو `TWILIO_MODE=mock`
