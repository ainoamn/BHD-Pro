# موجة CB — إبطال كاش POS عند عكس تعديل/تحويل + تلميح مزامنة خلفية

**التاريخ:** 28 يوليو 2026

## الهدف

1. `reverseLastAdjust` و عكس التحويل في المنتجات كانا يغيّران المخزون دون `invalidatePosCatalog` — فجوة بعد موجة BU.
