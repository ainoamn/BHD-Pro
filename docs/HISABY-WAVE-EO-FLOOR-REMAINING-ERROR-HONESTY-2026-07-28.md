# موجة EO — صدق أخطاء خريطة الطاولات المتبقية + تحميل KDS

**التاريخ:** 28 يوليو 2026

## الهدف

بعد EC (أخطاء نقل/دمج/تقسيم)، بقيت عمليات الصالة (تحميل الأرضية، إضافة صنف، كمية، حذف، تسوية مقعد/متساوية، سفري، بذرة الصالة) وتحميل المطبخ تعرض `actionFail` عاماً.

## التغييرات

| ملف | ماذا |
|-----|------|
| `resto/page.tsx` | `apiErrorMessage` للعمليات المتبقية على الأرضية |
| `kitchen/page.tsx` | صدق فشل تحميل طابور المطبخ |
| `utils.ts` | خريطة `tableId is required for dine-in` |

## سلوك

- فشل إضافة/تعديل/حذف/تسوية → رسالة Nest (مترجمة عند التعرّف)

## التالي

Cloudflare / Sentry / OTP يدوياً.
