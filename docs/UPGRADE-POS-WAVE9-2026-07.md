# ترقية Hisaby — Wave 9 POS (يوليو 2026)

**الهدف:** ثقة المزامنة الأوفلاين، استمرارية بين الأجهزة، وتنظيف السلال المعلّقة.

## ما شُحن

1. **طابور أوفلاين مقاوم للسمّ (poison-pill)** — فشل عنصر واحد لا يوقف باقي الطابور · عدّ محاولات · عزل بعد 3 فشلات · زر حذف المعزولة في شريط الكاشير
2. **مفضلة أصناف سحابية** — `GET/PUT /pos/favorites` · تخزين في `incentivesConfig.favoriteProductIds` · دمج مع localStorage عند فتح الكاشير
3. **TTL للسلال المعلّقة** — حذف تلقائي لما مضى عليه أكثر من 24 ساعة عند `GET /pos/drafts`
4. **اختصارات كمية** — `+` / `=` زيادة · `-` إنقاص لآخر سطر في السلة

## ملاحظات تشغيل

- لا توجد migration جديدة لهذه الموجة (المفضلة داخل JSON الشركة).
- العناصر المعزولة تبقى في IndexedDB حتى يحذفها الكاشير يدوياً.
