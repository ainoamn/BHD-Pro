# موجة EN — صدق أخطاء حذف/تعديل السلات المعلّقة

**التاريخ:** 28 يوليو 2026

## الهدف

بعد EI (تعليق السلة)، حذف وتعديل السلات المعلّقة كانا يعرضان `parkFail` عاماً ويخفيان رسالة الـ API (مسودة غير موجودة، موافقة مزدوجة، عربون…).

## التغييرات

| ملف | ماذا |
|-----|------|
| `pos/page.tsx` | `apiErrorMessage` عند `deleteParked` و`saveParkEdit` · toast نجاح الحذف |
| `pos-copy` | `deleteParkedOk` |

## سلوك

- فشل حذف/إعادة تسمية → toast بخطأ Nest الفعلي (مع الإبقاء على مسار 403 لعربون يحتاج موافقة)
