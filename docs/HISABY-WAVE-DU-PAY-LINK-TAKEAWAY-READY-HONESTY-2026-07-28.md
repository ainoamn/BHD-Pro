# موجة DU — صدق رابط الدفع + جاهزية السفري في المطبخ

**التاريخ:** 28 يوليو 2026

## الهدف

1. رابط الدفع كان يشترط اسم الضيف مع الهاتف؛ وجود هاتف فقط كان يُسكت الإشعار بينما الواجهة قد تظن أنه «لا هاتف».
2. عند اكتمال طلب سفري في المطبخ بلا هاتف، الاستجابة كانت بلا `notify` — الطاقم لا يرى فجوة الإشعار.

## التغييرات

| ملف | ماذا |
|-----|------|
| `resto.service.ts` → pay link | إشعار بالهاتف فقط (اسم احتياطي) · دائماً `notify` أو `no_phone` |
| `resto.service.ts` → kitchen READY | سفري مكتمل بلا هاتف → `no_phone` |
| `kitchen/page.tsx` | toast عند `no_phone` (لم يعد مُتخطّى) |

## سلوك

- رابط دفع + هاتف (باسم أو بدونه) → واتساب/SMS + toast حي/mock
- رابط دفع بلا هاتف → `no_phone` (الواجهة كانت تعرضه مسبقاً)
- مطبخ سفري جاهز بلا هاتف → تحذير واضح للطاقم
