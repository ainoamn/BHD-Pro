# Hisaby — موجة AT: صدق أخطاء واجهة مالية/مخزون/POS (26 يوليو 2026)

**الفرع:** `main` · بعد موجة AS  
**المستودع:** [ainoamn/BHD-Pro](https://github.com/ainoamn/BHD-Pro)

---

## ما شُحن

توحيد عرض رسائل الخادم عبر `apiErrorMessage` على صفحات كانت تبتلع المصفوفات/التفاصيل وتظهر fallback عام:

- رواتب · جهات اتصال · مخزون · جرد · تسليم · بنوك · مطالبات موظفين
- قوالب مستندات · ضرائب · مستخدمون · مرفقات · إعدادات dual
- مستندات نقدية · ورديات POS · مصروف كتب POS · ضريبة/OTA · مفاتيح API

الهدف: حراسات الخادم (حذف محمي، dual مرفوض، فترة مقفلة، سعر مربوط بـ FX…) تظهر كما هي في الواجهة.

---

## تحقق سريع

1. محاولة حذف قيد نظامي من دفتر اليومية → رسالة الخادم.  
2. حذف سعر صرف يوم FX-REV → رسالة واضحة.  
3. إغلاق وردية بفارق نقد مع dual → رسالة الموافقة إن فشلت.  
4. تعطيل قالب مستند مستخدم → رسالة الخادم إن وُجدت حراسة.
