## 1) ما تم برمجته ورفعه (حتى هذه الدقيقة)

### 1.1 المحاسبة والموارد البشرية (موجات A–G)
- فوترة مبيعات/مشتريات، عروض أسعار، إشعارات دائن/مدين، أوامر شراء، فواتير مجدولة، تحصيل وعكس دفعات، ضريبة 5%
- دفتر أستاذ + قيود تلقائية عند الإصدار/التحصيل
- رواتب ومطالبات موظفين: استحقاق وصرف عبر GL (`5210/2150`، `5220/2160`) + بنك عند الصرف
- التزامات دورية `/commitments` + cron + حسابات مصروف/مستحق + مرفقات
- مزامنة أرصدة البنوك مع GL + تحويل داخلي + اقتراحات مطابقة كشف الحساب
- مرفقات MVP + تنبيهات إدارة (مراجع مكررة / معاملات متشابهة) + deep-link للفاتورة
- Dual-control: `PAYROLL_PAY`، `CLAIM_PAY`، `BANK_INTERNAL_TRANSFER`
- أصول ثابتة، مراكز تكلفة، فروع، مشاريع، تقارير وتصدير، إقفال فترات

### 1.2 الكاشير (POS) — جاهز للبيتا
- بيع `/pos`: مخزون مستودع، نقد/بطاقة/تحويل، خصم، عميل/walk-in، إلغاء، سلات معلّقة
- دفع متعدد (split tender) + بقشيش (tip) + ملاحظات على السلة المعلّقة
- مسح باركود بالكاميرا، دور `CASHIER`، موافقات أونلاين + WhatsApp OTP (عند ضبط الأسرار)
- شارة NFC للموافقة المزدوجة (ليست دفعاً عبر شريك)
- ورديات لكل مستودع، تقرير Z وX، حركات نقد (in/out)، فارق إغلاق مع dual-control
- طابور مبيعات أوفلاين + كاش كتالوج حسب المستودع
- رصيد متجر: دفع/استرداد/إلغاء + GL حساب **2130** + واجهة محفظة في دفتر العناوين
- طباعة حرارية Web Serial (+ BLE تجريبي)، درج نقد، مشاركة إيصال/X-Z

### 1.3 الأمن والحماية (موجود الآن)
- كلمات مرور **bcrypt (12)** + سياسة قوية + قفل بعد 5 محاولات
- JWT قصير العمر + refresh مُقطَّع ومُدوَّر في DB + كوكيز httpOnly
- 2FA TOTP اختياري (أسرار مشفّرة عند وجود المفتاح)
- Helmet، ValidationPipe، Rate limit، Swagger معطّل في الإنتاج
- Dual-control (maker-checker) على عمليات حساسة في POS والمحاسبة
- فشل الإقلاع في الإنتاج إن كانت الأسرار ضعيفة/ناقصة
- **يوليو 25 مساءً — hardening إضافي:** CORS بدون `*.vercel.app` افتراضياً، منصّة إدارة من env فقط في الإنتاج، حد حجم/MIME للمرفقات، كاميرا مسموحة لـ POS

### 1.4 المنصة والتشغيل
- اشتراكات، بوابة دفع، لوحة منصة `/admin`، PWA خفيف، GeoIP، keep-warm لـ Render، توثيق نشر

| استقرار DNS / cold start Render | تشغيلي | مستمرة |

## 3) الأمن السيبراني — تقييم صادق

**المستوى:** أعلى من MVP نموذجي · يحتاج **hardening إنتاجي** · ليس «enterprise مُغلقاً».

### طبقات موجودة
1. HTTPS عند البروكسي (Vercel/Render/Cloudflare)
2. مصادقة قوية + جلسات + اختياري 2FA
3. صلاحيات أدوار + منع VIEWER من الكتابة
4. Maker-checker على العمليات الحساسة
5. تحقق إدخال + حد معدل طلبات
6. تشفير أسرار الدفع/2FA عند الضبط
7. رؤوس أمان على Next والـ API

### لا نعد بـ «لا يمكن الاختراق»
كل منصة ويب قابلة للهجوم نظرياً. الهدف العملي: تقليل السطح، فشل آمن، مراقبة، واستجابة. راجع أيضاً `SECURITY.md`.

### ما يجب على التشغيل قبل الإطلاق الواسع
```text
NODE_ENV=production
JWT_SECRET / JWT_REFRESH_SECRET / PAYMENT_SECRETS_KEY = قوية
CORS_ORIGIN = نطاقك فقط (لا * )
PLATFORM_ADMIN_EMAILS = إيميلات المشغّلين فقط
لا تفتح Postgres للعامة
نَفّذ: npx prisma migrate deploy
لا تشغّل prisma seed على الإنتاج
```
لمعاينة Vercel الاختيارية فقط: `CORS_ALLOW_VERCEL_PREVIEWS=1`

## 4) أين يذهب Hisaby؟ (رؤية المنتج)

**التموضع:** محاسبة سحابية عربية أولاً + كاشير حقيقي لمتاجر وخدمات الخليج، بهوية عُمانية (ضريبة، لغة، عملة، امتثال).

**ما يجعله فريداً (ليس مجرد نسخة من Wafeq/Odoo):**
1. **امتثال عُماني حي** — OTA + مسار VAT واضح + تقارير جاهزة للمراجع
2. **كاشير محاسبي واحد** — كل بيع يرحّل GL/مخزون/بنك بدون تكامل هش
3. **حماية مزدوجة عملية** — موافقات من جهاز المدير، واتساب، شارة NFC
4. **أوفلاين متجر** — يعمل عند انقطاع النت ثم يزامن بأمان
5. **مدفوعات خليجية** — ثواني/محافظ/NFC شريك داخل نفس الإيصال والدفتر
6. **مساعد ذكي بإشراف بشري** — تنبيهات مخزون/ازدواج دفعات/اقتراحات تسعير مربوطة بتنبيهات الإدارة (لا AI وهمي)

## 5) خطة التطوير الكاملة (موجات قادمة)

### الموجة H — تثبيت الإنتاج والأمن (1–2 أسابيع)
- تأكيد migrations على Neon/Render
- 2FA إلزامي لـ ADMIN/MANAGER (إعداد شركة)
- WAF/Cloudflare أمام login
- `npm audit` + ترقية الحزم الحرجة
- مراقبة أخطاء (Sentry) + تنبيه فشل migrations
- اختبار موافقات+كاميرا على Android/iOS حقيقي

### الموجة I — امتثال عُمان (OTA) (2–4 أسابيع)
- ربط API حقيقي للفاتورة الإلكترونية + حالات الإرسال/الرفض
- سجل تدقيق لكل مستند ضريبي
- لوحة حالة الامتثال في `/vat`

### الموجة J — مدفوعات عند الكاونتر (2–4 أسابيع)
- شريك بوابة (بطاقة/محفظة/NFC pay)
- تسوية تلقائية إلى حساب بنك Hisaby + قيد GL
- إيصالات واضحة للطرق المختلطة (بناءً على split tender الحالي)

### الموجة K — أوفلاين المتجر (2–3 أسابيع)
- مزامنة دلتا للمخزون والكتالوج
- قواعد تعارض + إعادة تسعير من الخادم دائماً
- Capacitor فقط إن فشلت PWA (كاميرا/طباعة/خلفية)

### الموجة L — الذكاء المساعد (مستمر)
- استبدال صفحة AI الوهمية بمساعد مربوط بـ management-alerts
- اقتراح إعادة طلب، تنبيه بطء تحصيل، ازدواج مراجع
- كل اقتراح يحتاج موافقة محاسب/مدير

### الموجة M — سهولة الاستخدام والتميّز UX
- Onboarding عربي أقصر (5 دقائق لفتح أول بيع)
- اختصارات كاشير أكبر للمس
- تقارير «قصة اليوم» لغير المحاسبين
- قوالب قطاعات (بقالة، صالون، مطعم خفيف)
