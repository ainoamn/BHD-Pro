# أنظمة حسابي — ربط دائم

**آخر تحديث:** 28 يوليو 2026

المحاسبة والكاشير والمطاعم تعمل على **نفس الشركة** دائماً:

- لا حاجة لربط يدوي أو مفتاح تكامل بين الأنظمة
- المستخدمون والمخزون وجهات الاتصال والحسابات مشتركة
- عند فتح حالة الربط (`/pos/link` أو `/resto/link`) يُفعَّل الربط تلقائياً إن كان ناقصاً
- فصل الأنظمة معطّل في الـ API؛ إخفاء وحدة لاحقاً يكون عبر **الباقة / الاشتراك**

متغيرات الشركة: `posLinkedAt` و `restoLinkedAt` تُضبط عند التسجيل وتُحافظ عليها الخدمة.
