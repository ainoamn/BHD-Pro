# ترقية Hisaby — Wave 16 POS (يوليو 2026)

**الهدف:** استدعاء سريع للسلات المعلّقة، عدم فقدان السلة عند إعادة التحميل، ومنع البيع المكرر بالخطأ.

## ما شُحن

1. **بحث السلات المعلّقة + هاتف العميل**
   - `listDrafts` يُلحق `contact { name, phone }`
   - فلتر بالاسم / الهاتف / الملاحظة
   - عمر السلة من `updatedAt` · شرائح سبب التعليق

2. **استعادة السلة بعد التحديث**
   - حفظ تلقائي في `localStorage` لكل شركة/مستخدم
   - عند الفتح: عرض استعادة أو تجاهل (TTL 12 ساعة)

3. **تحذير البيع المكرر**
   - بصمة السلة (أصناف + أسعار + عميل + إجمالي)
   - إن تطابقت خلال 60 ثانية → تأكيد قبل المتابعة

## مؤجّل

- SoftPOS · لوحة متعددة الشركات · وضع تدريب · كوبونات · شاشة عميل ثانية
