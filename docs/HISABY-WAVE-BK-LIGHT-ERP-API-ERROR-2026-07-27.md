**التاريخ:** 27 يوليو 2026  
**بعد:** Wave BJ

## ما أُكمل

| البند | التفاصيل |
|-------|----------|
| إعادة تقييم FX | حقول/جدول متوافقان مع الوضع الفاتح |
| إقفال الفترات | تنقّل السنة والأزرار مقروءة في الوضع الفاتح |
| جرد المخزون | نماذج وتفاصيل بألوان فاتحة/داكنة |
| `CreatableSelect` | مكوّن مشترك لم يعد يفرض خلفية داكنة |
| `apiErrorMessage` | ترجمة أخطاء Nest الشائعة للعربية + صفحة الدعوة تستخدمه |
| Keep-warm | رابط افتراضي `hisaby-api.onrender.com` |
| دليل المراسلات | يذكر حقول `/api/health` للبريد/واتساب/SMS |
