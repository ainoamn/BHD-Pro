## 1) ملخص تنفيذي

المنتج **منشور ويعمل** (Vercel + Render + Neon) بمنصتين مترابطتين:

| المنتج | المسار | الحالة |
|--------|--------|--------|
| **حسابي للمحاسبة** | `/dashboard` وما يتفرع منه | جاهز للبيتا — فواتير، مخزون، GL، تقارير، ضريبة |
| **حسابي للكاشير (POS)** | `/pos` | جاهز للبيتا — بيع سريع، مخزون مستودع، حماية مزدوجة، كاميرا باركود، موافقات أونلاين |
| لوحة المنصة | `/admin` | تعمل لمشغّلي المنصة |

فجوات واضحة المتبقي: WhatsApp OTP / NFC، أوفلاين كامل، ESC/POS حقيقي، OTA e-invoice، AI حقيقي.

## 2) ما أنجزته المحاسبة

- فواتير مبيعات/مشتريات، عروض، إشعارات دائنة/مدينة، أوامر شراء، فواتير مجدولة
- تحصيل ودفعات، عكس التحصيل، تراجع عن الإرسال، إلغاء فاتورة
- دليل حسابات، قيود يومية، ترحيل GL تلقائي عند الإرسال والتحصيل
- مخزون ومنتجات، مستودعات، جرد، تحويل بين مستودعات، أرصدة `WarehouseStock`
- تقارير (مبيعات، مشتريات، VAT، مخزون…) + تصدير PDF/Excel/CSV
- فترات محاسبية (إقفال/فتح)، معدلات ضريبية، بنوك وتسوية
- أصول ثابتة، رواتب، مراكز تكلفة، فروع، مشاريع
- حماية مزدوجة (maker-checker) على إلغاء فاتورة وعكس دفعات
- ربط اختياري مع الكاشير (`pos_*` على الشركة + مفتاح تقني)
- PWA خفيف (manifest + service worker) + اختصارات كاشير/محاسبة
- Onboarding checklist ومؤشرات لوحة أذكى (يوليو 2026)
- أكواد خصم الاشتراك مربوطة بمسار الدفع (`promoCode` + عروض `PlanOffer`)
- GeoIP للزيارات عبر ترويسات Cloudflare/Vercel
- Keep-warm لـ Render عبر GitHub Actions كل 10 دقائق
- إخفاء واجهة AI التجريبية من القائمة الجانبية

## 5) خطة مستقبلية — مراحل A / B / C

### المرحلة A — تثبيت التشغيل (قصير)
- تطبيق migrations الجديدة على الإنتاج (`approval_requests`, `cashier_shifts_otp`, …)
- اختبار الكاميرا على Android/iOS + موافقات المدير من جهاز ثانٍ
- استقرار الدومين (Cloudflare / A record) وتقليل cold start على Render

### المرحلة B — نضج الكاشير والأمان (متوسط)
- WhatsApp OTP + إشعار المدير عند طلب موافقة
- ائتمان متجر / سياسات استرداد أوسع
- موافقة مزدوجة على فارق إغلاق الوردية
- طباعة ESC/POS / WebUSB أو جسر طباعة محلي

### المرحلة C — توسّع وتكامل (لاحق)
- أوفلاين-first مع طابور مبيعات
- دفع NFC/محافظ عبر شركاء بوابة
- OTA e-invoice كامل + مراقبة
- تطبيقات جوال/تابلت أصيلة أو Capacitor فوق نفس `/pos`
- AI تشغيلي (تنبيهات مخزون، اقتراحات تسعير) مع إشراف بشري

## 6) أخطاء تشغيل معروفة (مختصر)

- بعض الشبكات تفشل على مسار Vercel Anycast — راجع DNS
