# موجة BE — صقل مستودع الموظف (جلسة + مطاعم + توثيق)

**التاريخ:** 27 يوليو 2026  
**بعد:** Waves BC + BD

## ما أُكمل

| البند | التفاصيل |
|-------|----------|
| جلسة المستخدم | `restoreSession` يحفظ `defaultWarehouseId` / `defaultWarehouse` بعد إعادة التحميل |
| تسليم مؤجّل | بعد بيع مؤجّل ناجح تُحدَّث قائمة الانتظار فوراً |
| ورديات المطاعم | الكاشير يفتح الصندوق على مستودعه المنزلي (لا يُرفض بسبب قفل BD) |
| تنبيه تعارض | إن اختلف مستودع المنزل عن مخزن المطعم يظهر تنبيه للمدير/الكاشير |
| توثيق إنتاج | قائمة الإطلاق تذكر migration المستودع + روابط موجات BC/BD |

## تذكير تشغيل

1. على Render: `npx prisma migrate deploy` (يشمل `20260727133000_user_home_warehouse_pos_fulfillment`).
2. من **المستخدمون** عيّن مستودع الموظف لكل كاشير.
3. لكاشير المطاعم: اجعل مستودعه المنزلي = مخزن المطعم.
