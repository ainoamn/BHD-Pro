# موجة CS — عرض نتيجة إشعار قائمة الانتظار في الواجهة

**التاريخ:** 28 يوليو 2026

## الهدف

API قائمة الانتظار يحفظ ويعيد `notifyResult` (`ok` / `mock` / `fail:…`) منذ Wave CI، بينما الواجهة كانت تعرض القناة فقط عند `NOTIFIED` — فيبدو الإشعار «مرسلاً» حتى في وضع mock.

## التغييرات

| ملف | ماذا |
|-----|------|
| `resto/waitlist/page.tsx` | شارة بجانب الحالة: قناة + نتيجة (`وُصل` / `mock` / `فشل`) |
| `resto-copy.ts` | `notifyResultOk` / `Mock` / `Fail` |

## التالي

Cloudflare / Sentry / `REDIS_URL` / قالب OTP واتساب يدوياً.
