**التاريخ:** 28 يوليو 2026

## الهدف

صفحات قائمة الانتظار والحجوزات والسفري والتوصيل كانت تعرض `actionFail` عاماً عند فشل الـ API وتخفي سبب Nest (طاولة ناقصة، حجز غير صالح، إلخ).

## التغييرات

| ملف | ماذا |
|-----|------|
| `waitlist/page.tsx` · `reservations/page.tsx` · `takeaway/page.tsx` · `delivery/page.tsx` | `apiErrorMessage` في التحميل والإجراءات |
| `utils.ts` | خرائط عربية لأخطاء الانتظار/الحجز الشائعة |

## سلوك

- فشل إضافة/إشعار/إجلاس/تحديث حالة → toast برسالة الـ API (مترجمة عند التعرّف)
