# موجة BL — وضع فاتح لوحة التحكم + إيصالات تسليم + صدق CI

**التاريخ:** 27 يوليو 2026  
**بعد:** Wave BK

## ما أُكمل

| البند | التفاصيل |
|-------|----------|
| إيصالات التسليم | نماذج/جدول متوافقان مع الوضع الفاتح |
| لوحة التحكم | `stats` + `quick-actions` بألوان فاتحة/داكنة |
| جرد المخزون | هيكل النوافذ المنبثقة لم يعد يفرض خلفية داكنة |
| `QueryError` | مفاتيح `common.loadFailed` / `common.retry` بدل نص عربي ثابت |
| CI | حذف `keep-api-awake.yml` المكرر الذي ينتهي دائماً بنجاح |

## تحقق

- `/dashboard` و`/delivery-notes` و`/stock-counts` في الوضع الفاتح
- واجهة إنجليزية تظهر «Could not load data» / «Retry»
