# موجة BJ — إكمال الوضع الفاتح + صحة واتساب/SMS + throttles عامة

**التاريخ:** 27 يوليو 2026  
**بعد:** Wave BI

## ما أُكمل

| البند | التفاصيل |
|-------|----------|
| مستخدمون / شجرة صلاحيات | ألوان متوافقة مع الوضع الفاتح |
| أسعار الصرف | بطاقة التحويل لا تفرض خلفية داكنة |
| `/api/health` | `whatsappConfigured` / `smsConfigured` + أوضاعها |
| مستندات عامة + دفع عام | `@Throttle` 60/دقيقة |
| صفحة إكمال الدعوة | أخطاء Nest الإنجليزية تُستبدل بنص محلي |

## تحقق

- `/api/health` → حقول واتساب/SMS ظاهرة
- `/users` و`/exchange-rates` مقروءة في الوضع الفاتح
