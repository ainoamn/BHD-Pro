## ما شُحن

### صدق واجهة
- **صالة المطاعم:** فشل تحميل المحطات + المعدّلات يظهر خطأ + إعادة عند إضافة أصناف (بدل إخفاء الخيارات)
- **قائمة المطاعم:** فشل تحميل المحطات يظهر شريط خطأ + إعادة للمدير
- **لوحة أنظمة حسابي (لوحة التحكم):** فشل حالة الربط يظهر خطأ + إعادة؛ فشل «تفعيل الربط» يظهر toast
- **مركز الربط المشترك:** فشل تحميل حالة POS/مطاعم يفشل بالكامل مع خطأ + إعادة (لا حالة «…» صامتة)

---

## تحقق سريع

1. أوقف API وافتح طلب صالة — شريط فشل للمحطات/المعدّلات.  
2. `/resto/menu` مع API متوقف — شريط محطات للمدير.  
3. لوحة التحكم / مركز الربط مع API متوقف — خطأ + إعادة لا نقاط تحميل أبدية.
