# ترقية Hisaby — POS Wave 4 (يوليو 2026)

## منجز

### 1) ورديات حسب المستودع
- وردية مفتوحة واحدة لكل `(company, warehouse)` (أو الدرج الافتراضي عند غياب المستودع).
- المبيعات والاسترداد تُربَط بوردية المستودع الحالي.
- واجهة `/pos/shifts` تختار المستودع وتزامن مع `hisaby-pos-warehouse-id`.

### 2) طباعة ESC/POS (Web Serial)
- `frontend/src/lib/pos-escpos.ts`
- عند طباعة الإيصال: محاولة Web Serial ثم الرجوع لطباعة المتصفح 80mm.

### 3) طابور مبيعات أوفلاين
- IndexedDB: `pos-offline-queue.ts`
- عند `navigator.onLine === false` أو فشل شبكة: يُحفظ البيع محلياً ويُزامَن عند `online`.
- الإلغاء/الاسترداد يتطلبان شبكة (بدون طابور).

### 4) استرداد بكميات
- نافذة اختيار كميات البنود موجودة (من الموجة السابقة) + dual-control.
