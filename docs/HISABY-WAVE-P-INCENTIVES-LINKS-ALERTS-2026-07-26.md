## ما شُحن

### 1) صدق أخطاء التحميل
- إعدادات حوافز الكاشير — لا تُعرض قيم صفرية كإعدادات حقيقية عند الفشل
- طباعة QR للطاولات — خطأ + إعادة محاولة
- لوحات ربط POS / مطاعم — فشل التحميل بدل «غير مربوط»
- جرس التنبيهات — فشل كلي يظهر خطأ+retry وليس «لا تنبيهات»
- مطبخ Expo — لا يُعرض empty مع شريط الخطأ معاً

### 2) أمن تشغيلي (`@Throttle`)
- checkout فاتورة (مصادق + عام)
- AI `propose` · FX `post`
- POS: incentives config + link activate/deactivate/generate/confirm
- مطاعم: نفس عمليات الربط
