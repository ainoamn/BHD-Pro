# موجة EG — صدق تنبيه واتساب عند فتح/إغلاق الوردية

**التاريخ:** 28 يوليو 2026

## الهدف

إغلاق الوردية كان يُرسل تقرير Z بالبريد فقط؛ فتح الوردية بلا أي تنبيه للطاقم/الإدارة عبر واتساب — فجوة مقارنة بتنبيهات 86 وطلبات QR.

## التغييرات

| ملف | ماذا |
|-----|------|
| `pos.service.ts` | `notifyStaffWhatsAppAlert` · `staffNotify` عند `openShift` / `closeShift` (مخزن، من فتح/أغلق، افتتاح/فرق نقد) |
| `api.ts` · `pos-shifts-view.tsx` · `pos-copy` | toast حي/mock/فشل/تخطّي |

## سلوك

- فتح وردية → واتساب للأرقام المهيأة + toast صدق
- إغلاق → نفس التنبيه مع المتوقع/المحسوب/الفرق (+ zEmail كما كان)
- بلا أرقام أو واتساب غير مهيأ → `skipped` بصراحة

## التالي

Cloudflare / Sentry / OTP يدوياً · هيّئ `whatsappNotifyPhones` في إعدادات الأمان.
