# موجة EM — صدق أخطاء إعدادات وإدارة المطعم

**التاريخ:** 28 يوليو 2026

## الهدف

صفحات الإعدادات والوصفات والتقارير وExpo ولوحة الحيّة وطباعة QR كانت تبتلع أخطاء الـ API وتظهر `actionFail` عاماً.

## التغييرات

| ملف | ماذا |
|-----|------|
| `settings/page.tsx` | `apiErrorMessage` لحفظ الأجزاء/SLA/حجز/محطات/أقسام/ديمو/QR |
| `recipes` · `reports` · `expo` · `board` · `qr-print` | نفس الصدق عند التحميل والحفظ/الحذف/التقديم |

## سلوك

- فشل حفظ إعداد أو وصفة أو تحميل تقرير → toast/نص بخطأ الـ API الفعلي

## التالي

Cloudflare / Sentry / OTP يدوياً.
