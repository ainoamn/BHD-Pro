# Hisaby — موجة AN: عكس رصيد متجر + حماية حذف فروع/مستودعات (26 يوليو 2026)

**الفرع:** `main` · بعد موجة AM  
**المستودع:** [ainoamn/BHD-Pro](https://github.com/ainoamn/BHD-Pro)

---

## ما شُحن

### 1) عكس تمويل رصيد المتجر
- `reverseStoreCreditFunding` (`REV-SC:{journalId}`) لقيود `SC-ADJ:*` و `POS-SC-TOPUP:*`
- `POST /contacts/:id/store-credit-reverse-last` + dual-control `STORE_CREDIT_ADJUST`
- يعيد رصيد المحفظة · ويعكس حركة نقد POS عند التوب-أب النقدي إن وُجدت
- حذف اليومية يرفض قيود تمويل المتجر ويوجّه للعكس عبر جهات الاتصال
- واجهة جهات الاتصال: زر «عكس آخر تمويل»

### 2) تعطيل بدل حذف عند الروابط
- فرع: تعطيل إن وُجدت مستودعات/موظفين/مشاريع/مراكز/أصول/بنوك/رواتب
- مستودع: رفض رصيد غير صفري أو افتراضي POS/مطعم · تعطيل عند حركات/ورديات/جرد/تسليم
- مركز تكلفة: تعطيل عند قيود/فواتير/مشاريع
- موظف: تعطيل عند مسيرات/مطالبات

### 3) سلامة جهات الاتصال
- تعطيل جهة اتصال مرفوض إن بقي رصيد متجر غير صفري
- حماية مزدوجة على تعديل/عكس رصيد المتجر

### 4) صدق واجهة
- صفحة جهات اتصال POS تعرض رسالة API عند فشل الحفظ

---

## تحقق سريع

1. تعديل رصيد متجر → reverse-last → قيد `REV-SC` والرصيد يعود.  
2. توب-أب POS نقدي → reverse → محفظة + حركة نقد.  
3. حذف فرع مرتبط → deactivate وليس hard delete.  
4. مستودع برصيد → 400 · بمخزون صفر وتاريخ → deactivate.  
5. حذف عميل برصيد متجر → 400.
