# ترقية Hisaby — Wave 13 POS (يوليو 2026)

**الهدف:** حوكمة خصم السطر، سرعة استلام النقد باللمس، وشفافية طابور الأوفلاين.

## ما شُحن

1. **حد خصم السطر + موافقة `POS_LINE_DISCOUNT`**
   - إعدادات: `maxLineDiscountAmount` (افتراضي 5) و `maxLineDiscountPercent` (افتراضي 20)
   - عند تجاوز أي حد: موافقة مزدوجة عند الدفع
   - مؤشر بصري على السطر · إجراء منفصل في إعدادات التحكم المزدوج
   - موافقة واحدة تغطي تجاوز السعر وخصم السطر معاً عند الحاجة (`assertApprovedForActions`)

2. **لوحة نقد باللمس**
   - لوحة أرقام عشرية
   - شرائح: المبلغ بالضبط · تقريب لأعلى · +1 / +5 / +10 / +20
   - حساب الباقي قبل التأكيد

3. **ورقة تفصيل طابور الأوفلاين**
   - من شارة الانتظار / العزل في شريط POS
   - عرض المبيعات والعمليات · المحاولات · آخر خطأ · حالة العزل
   - مزامنة الكل · حذف عنصر · حذف المعزولة

## إعداد

Security / Dual control:
- تفعيل `POS_LINE_DISCOUNT`
- ضبط حد المبلغ والنسبة حسب سياسة المتجر

## مؤجّل

- SoftPOS عند توفر قالب المورّد (`POS_SOFTPOS_DEEP_LINK_TEMPLATE`)
- لوحة `/pos/board` متعددة الشركات عند وجود تبديل شركة
