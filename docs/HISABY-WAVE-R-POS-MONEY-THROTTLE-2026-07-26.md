## ما شُحن

### 1) صدق أخطاء التحميل — كاشير
- إقلاع المخازن/العملاء — شريط خطأ + إعادة محاولة
- كتالوج البيع — خطأ صادق بدل «أضف منتجات» عند فشل الشبكة بلا كاش
- إيصالات حديثة — خطأ + إعادة في الشريط واللوحة
- ربط POS/مطاعم — فشل تحميل المخازن يفشل الـ refresh بالكامل (لا قائمة فارغة صامتة)

### 2) مطاعم
- قائمة إضافة أصناف في تفاصيل الطلب — خطأ + إعادة
- وصفات: فشل `getProducts` يفشل التحميل كاملاً (لا مكوّنات فارغة صامتة)

### 3) أمن تشغيلي (`@Throttle`)
- فواتير: status / payments / batch / reverse / reverse-all / send
- مخزون: adjust / transfer
- بنوك: transfer
- مطاعم: send to KDS / settle by-seat / settle equal
