# إصلاح بطء المطبخ والكاشير

**التاريخ:** 29 يوليو 2026

## العَرَض

شاشة المطبخ (KDS) والكاشير (`/pos`) بطيئة جداً عند التحميل وتحديث البيانات.

## الأسباب

| المسار | المشكلة |
|--------|---------|
| POS — فتح الوردية | `GET /pos/shifts/current` كان يبني تقرير Z كاملاً حتى لفحص «هل الورديّة مفتوحة؟» |
| POS — إحصائيات اليوم | `getTodayStats` يجلب كل فواتير اليوم ثم يلخّصها في JS |
| POS — العملاء | `GET /contacts` بدون حد + مسح كل فواتير الشركة المفتوحة للأرصدة |
| مطبخ — الواجهة | REST مزدوج مع SSE عند الفتح؛ poll كل 5 ثوانٍ؛ `load()` بعد كل إجراء رغم SSE |
| مطبخ — الخادم | heartbeat SSE كل 25 ثانية يعيد بناء الطابور كاملاً |

## الإصلاحات

### Backend
- `getCurrentShift(..., { light: true })` — استعلام خفيف بدون Z وبدون حركات نقد.
- `GET /pos/shifts/current?light=1` في الـ controller.
- `getTodayStats` — `aggregate` / `count` بدل `findMany` + حلقة.
- `contacts.findAll` — `take` 40/80 + أرصدة الفواتير المفتوحة فقط لجهات الاتصال المُرجَعة.
- `kitchenStream` heartbeat من 25s → 35s.

### Frontend
- فحص الوردية في `pos-shell` و`resto` وشريط ops في الكاشير بـ `{ light: true }`.
- صفحة الورديات (`pos-shifts-view`) تبقى على الوضع الكامل (Z).
- مطبخ: لا REST أولي إن وصل SSE خلال 2.5s؛ poll احتياطي 12s؛ تخطّي `load()` بعد الطفرات عند SSE حي.

## نشر

1. **Render** — إعادة نشر الـ API (ضروري لإصلاحات الـ backend).
2. **Vercel** — نشر الواجهة تلقائياً من `main`.
3. تحديث قوي للمتصفح بعد Ready.

## تحقق يدوي

- `/pos`: فتح الكاشير أسرع؛ شريط اليوم يعمل؛ صفحة الورديات ما زالت تعرض Z.
- `/resto/kitchen`: تحديث عبر SSE بدون طلبات REST زائدة بعد bump/rush/hold.
- قائمة العملاء في الكاشير محدودة (~80) وليست كل قاعدة العملاء.

## إلغاء / استرداد بطيء (~دقيقة) — 29 يوليو (إضافة)

### السبب
1. الخادم كان **ينتظر** إرسال واتساب/بريد/SMS للعميل قبل إرجاع الرد (حتى 12–36 ثانية لكل قناة).
2. الواجهة كانت **تنتظر** إعادة تحميل المبيعات + الإحصائيات + الكتالوج قبل إغلاق نافذة الموافقة.
3. الإلغاء كان يعكس الدفعات **مرتين** (`reverseAllPayments` ثم `updateStatus` يفعل نفس الشيء).
4. الواجهة كانت **تخفي** الفواتير ذات الحالة `CANCELLED` من شريط آخر المبيعات.
