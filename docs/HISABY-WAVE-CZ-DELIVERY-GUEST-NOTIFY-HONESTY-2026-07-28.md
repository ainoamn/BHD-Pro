# موجة CZ — إشعار ضيف التوصيل عند «في الطريق» / «تم التسليم» بصدق

**التاريخ:** 28 يوليو 2026

## الهدف

تحديث حالة التوصيل لم يكن يُشعر الضيف. الموظفون يفترضون أن الضيف عَلِم عند الضغط على «في الطريق» أو «تم التسليم».

## التغييرات

| ملف | ماذا |
|-----|------|
| `resto-guest-notify.service.ts` | أنواع `DELIVERY_OUT` / `DELIVERY_DONE` + نصوص |
| `resto.service.ts` | إشعار عند انتقال الحالة إلى OUT أو DELIVERED · إرجاع `notify` |
| `delivery/page.tsx` | toast صادق (حي / mock / فشل) |
| `api.ts` | نوع `notify` على تحديث التوصيل |

## سلوك

- بدون هاتف ضيف: لا إشعار (صامت)
- mock → 🧪 · live → نجاح · فشل قناة → تحذير
- لا يُعاد الإشعار إن أُعيد ضبط نفس الحالة

## التالي

Cloudflare / Sentry / OTP يدوياً.
