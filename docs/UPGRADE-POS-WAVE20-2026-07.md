# ترقية Hisaby — Wave 20 POS (يوليو 2026)

**الهدف:** إرجاع بلا إيصال بضوابط مزدوجة، عدّاد انتهاء طلبات الموافقة، وإدخال الوزن العشري للمنتجات المباعة بالكيلو.

## ما شُحن

1. **إرجاع بلا إيصال (Blind return)**
   - `POST /pos/returns/blind` — إشعار دائن + إعادة مخزون بدون ربط بفاتورة أصلية
   - Dual-control إلزامي: `POS_BLIND_RETURN`
   - وجهات الإرجاع: نقد أو رصيد متجر (يتطلب عميلاً)
   - واجهة على أرضية الكاشير بجانب استرداد الإيصال

2. **عدّاد انتهاء الموافقة**
   - عدّاد حي على `/pos/approvals` للطلبات المعلّقة
   - عدّاد في نافذة الموافقة المزدوجة أثناء انتظار المدير

3. **البيع بالوزن**
   - حقل `Product.soldByWeight` + migration `20260726170000_product_sold_by_weight`
   - مزامنة الكتالوج ترسل العلم مع `unit`
   - عند الإضافة/المسح (بدون PLU وزن) يفتح لوحة أرقام عشرية (كجم)
   - تبديل في مخزون الكاشير السريع
