## ما شُحن

### 1) صدق أخطاء التحميل — كاشير
- **السلال المعلّقة** — فشل `listPosDrafts` يظهر شريط خطأ + إعادة محاولة بدل إخفاء الشريط بالكامل
- **مشتريات العميل الأخيرة** — فشل التحميل يظهر خطأ + إعادة بدل رسالة «لا مشتريات»
- **طابور الأوفلاين** (`pos-shell`) — فشل قراءة IndexedDB يظهر خطأ + إعادة بدل «الطابور فارغ»

### 2) أمن تشغيلي (`@Throttle`)
- POS: `DELETE drafts/:id` (إرجاع حجز نقدي) — 60/دقيقة (مطابق لـ discard)
- جرد مخزون: `POST :id/complete` — 20/دقيقة
- إذن تسليم: `POST :id/deliver` — 20/دقيقة
- رواتب: `PATCH :id/status` — 20/دقيقة
- قيود يومية: `POST` إنشاء قيد — 30/دقيقة

---

## تحقق سريع

1. أوقف API وافتح `/pos` — شريط السلال المعلّقة يظهر بخطأ+إعادة.  
2. اختر عميلاً مع API متوقف — مشتريات حديثة بخطأ لا «لا مشتريات».  
3. افتح طابور الأوفلاين مع فشل التخزين المحلي — رسالة فشل.  
4. حذف سلة معلّقة / إكمال جرد / تسليم / تغيير حالة راتب بسرعة متكررة يُحدّ بعد الحد.
