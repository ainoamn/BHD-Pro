# موجة DG — صدق إشعار العميل بعد مزامنة طابور الكاشير دون اتصال

**التاريخ:** 28 يوليو 2026

## الهدف

عند عودة الشبكة كان flush يُظهر «تمت المزامنة» فقط، بينما الخادم يرسل إيصال/إلغاء/استرجاع دون toast صدق للواجهة.

## التغييرات

| ملف | ماذا |
|-----|------|
| `pos-notify-toast.ts` | مساعد مشترك + تجميع نتائج flush |
| `pos-offline-sync.ts` | قراءة `customerNotify` من بيع/إلغاء/استرجاع · `notifyAgg` |
| `pos/page.tsx` · `pos-shell.tsx` | toast ملخّص واحد بعد المزامنة |

## سلوك

- أثناء الأوفلاين: لا ادّعاء إرسال (`saleQueued` كما كان)
- بعد sync ناجح: toast مزامنة + toast صدق مجمّع (حي/mock/جزئي/فشل) إن وُجدت نتائج
