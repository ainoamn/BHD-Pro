# ترقية Hisaby — Wave 17 POS (يوليو 2026)

**الهدف:** إيجاد الإيصال بسرعة، موافقة PIN باللمس، وشاشة عميل ثانية تقلل النزاع على الإجمالي.

## ما شُحن

1. **بحث درج الإيصالات (F7)**
   - `GET /pos/sales/recent?q=` يبحث برقم الإيصال / هاتف أو اسم العميل / المبلغ (±0.005)
   - حقل بحث في درج الإيصالات مع عرض اسم وهاتف العميل

2. **لوحة PIN باللمس للموافقة المزدوجة**
   - في تبويب PIN داخل `DualApprovalModal`: لوحة أرقام + نقاط مخفية + مسح/حذف
   - مناسبة للشاشات اللمسية دون لوحة مفاتيح النظام

3. **شاشة العميل الثانية**
   - مسار `/pos/display` (بدون شريط POS)
   - نشر السلة/الإجمالي/الباقي عبر `BroadcastChannel` + مرآة `localStorage`
   - زر «شاشة العميل» من صفحة الكاشير
