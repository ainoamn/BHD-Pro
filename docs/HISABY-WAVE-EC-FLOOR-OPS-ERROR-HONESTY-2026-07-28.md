# موجة EC — صدق أخطاء عمليات خريطة الطاولات

**التاريخ:** 28 يوليو 2026

## الهدف

النقل / الدمج / التقسيم / إرسال المطبخ / الإغلاق على خريطة الطاولات كان يخفي سبب فشل الـ API خلف `actionFail` عام، بينما صفحة تفاصيل الطلب تستخدم `apiErrorMessage`. كذلك نجاح العمليات كان صامتاً.

## التغييرات

| ملف | ماذا |
|-----|------|
| `resto/page.tsx` | `apiErrorMessage` في catch للنقل/الدمج/التقسيم/المطبخ/الإغلاق/الفراغ/رابط الدفع · toast نجاح · تلميح هاتف عند فتح طاولة |
| `utils.ts` → `apiErrorMessage` | ترجمات عربية لأخطاء المطبخ/الطاولة/الفوترة · عرض الرسالة بدل إخفائها |
| `resto-copy` | `transferOk` / `mergeOk` / `splitOk` / `softCloseOk` / `guestPhoneHint` |

## سلوك

- فشل النقل لطاولة مشغولة → رسالة واضحة لا «تعذر تنفيذ العملية» فقط
- إرسال مطبخ ناجح → toast `sendOk`
- فتح طاولة بلا هاتف → تلميح اختياري لتفعيل واتساب لاحقاً

## التالي
