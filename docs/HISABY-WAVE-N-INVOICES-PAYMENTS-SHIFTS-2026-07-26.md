## ما شُحن

### 1) صدق أخطاء التحميل
- محاسبة: قائمة الفواتير — `QueryError` بدل «لا فواتير»
- إعدادات بوابات دفع الشركة — خطأ + إعادة محاولة
- ورديات POS — خطأ صادق على الوردية الحالية
- مطاعم: ورديات (لا تُخلط مع «تحتاج مخزن»)، سفري، توصيل
- تفاصيل بوابة منصة `/admin/gateways/[slug]` — إعادة محاولة
- إعادة تقييم عملات — زر إعادة معاينة عند الفشل

### 2) أمن تشغيلي (`@Throttle`)
- `PATCH` بوابات شركة + منصة
- `POST` اشتراك checkout + mock-confirm
- `PUT`/`DELETE` مستخدمي الشركة
- `POST` إرسال فاتورة VAT إلى OTA
