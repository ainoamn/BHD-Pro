# Hisaby — موجة AX: تنقل موبايل + استقرار لوحة التحكم (27 يوليو 2026)

**الفرع:** `main` · بعد موجة AW  
**المستودع:** [ainoamn/BHD-Pro](https://github.com/ainoamn/BHD-Pro)

---

## المشكلة

- كاشير / محاسبة / مطاعم على الهاتف: صف أيقونات علوي مزدحم يصعّب الاستخدام.
- لوحة الأدمن بلا خروج / رجوع / انتقال للأنظمة في قائمة الموبايل.
- لوحة التحكم تظهر بطاقات «مقفلة» مبعثرة 10–20 ثانية ثم تستقر (انتظار صلاحيات الباقة + حركة Framer).

---

## ما شُحن

1. **محاسبة:** شريط علوي على الموبايل = زر قائمة + تنبيهات فقط · خروج ولغة وسمة وأنظمة داخل الشريط الجانبي.
2. **كاشير / مطاعم:** زر قائمة يفتح درج كامل (أنظمة + أقسام + خروج) · إخفاء صف الأيقونات تحت `lg`.
3. **أدمن:** درج موبايل + فوتر سطح مكتب: محاسبة / كاشير / مطاعم · رجوع للتطبيق · تسجيل خروج.
4. **لوحة التحكم:** لا تُرسم الودجات حتى اكتمال الإحصائيات + modules · إزالة دخول Framer المتدرّج · مخطط نقدي ينتظر قياس الحاوية.

---

## تحقق سريع

1. هاتف: `/dashboard` → قائمة واحدة · خروج من الشريط.  
2. `/pos` و `/resto` → قائمة واحدة تحتوي الأنظمة والخروج.  
3. `/admin` → قائمة فيها خروج + الأنظمة.  
4. فتح لوحة التحكم: مؤشر تحميل واحد ثم تخطيط ثابت (بدون بطاقات Cash flow/Invoices المبعثرة).
