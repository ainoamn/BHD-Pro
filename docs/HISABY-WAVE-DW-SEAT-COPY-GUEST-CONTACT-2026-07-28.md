# موجة DW — نسخ بيانات الضيف إلى الطلب عند الإجلاس

**التاريخ:** 28 يوليو 2026

## الهدف

عند إجلاس حجز أو قائمة انتظار كان الطلب يُفتح بالملاحظات فقط دون `guestName` / `guestPhone` — فيفشل لاحقاً إشعار رابط الدفع / الإيصال / الإلغاء رغم أن الهاتف معروف في الحجز أو الانتظار.

## التغييرات

| ملف | ماذا |
|-----|------|
| `resto.service.ts` → إجلاس حجز | تمرير الاسم والهاتف لـ `openOrder` · تعبئة الطلب الموجود إن كان فارغاً |
| `resto.service.ts` → إجلاس انتظار | نفس النسخ + إرجاع الطلب بعد التحديث |

## سلوك

- طلب جديد من حجز/انتظار يحمل هاتف الضيف واسمه
- طلب مفتوح مسبقاً على الطاولة: يُكمَّل الاسم/الهاتف فقط إن كانا فارغين (لا يستبدل بيانات موجودة)
