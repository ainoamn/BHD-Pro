# موجة DY — صدق إشعار عدم حضور قائمة الانتظار

**التاريخ:** 28 يوليو 2026

## الهدف

حالة `NO_SHOW` في الانتظار كانت تُحدّث القاعدة فقط بلا إشعار للضيف وبلا زر في الواجهة — بخلاف الإلغاء والحجوزات.

## التغييرات

| ملف | ماذا |
|-----|------|
| `resto-guest-notify.service.ts` | نوع `WAITLIST_NO_SHOW` |
| `resto.service.ts` | إشعار عند الانتقال لـ NO_SHOW · منع إشعار «الطاولة جاهزة» لمدخل مغلق |
| `waitlist/page.tsx` · `resto-copy` | زر «لم يحضر» + toast صدق |

## سلوك

- NO_SHOW + هاتف → واتساب/SMS + toast
- بلا هاتف → `no_phone` بصراحة

## التالي

Cloudflare / Sentry / OTP يدوياً · لاحقاً: تذكير حجوزات تلقائي (cron).
